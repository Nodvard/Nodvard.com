Loslegen

Nodvard Deck läuft in Docker, auf einem Raspberry Pi 4 oder 5 genauso wie auf jedem x86-64-Rechner. Gebaut wird nichts, das fertige Image kommt von GitHub.

  1. Docker und Docker Compose bereitstellen. Auf einem Raspberry Pi brauchst du ein 64-Bit-System.
  2. Deck holen und starten.
    Im Terminal
    mkdir ~/nodvard-deck && cd ~/nodvard-deck
curl -fsSL -o compose.yml https://raw.githubusercontent.com/nodvard/deck/main/deploy/compose.standalone.yml
docker compose up -d

    Unter Windows sind das Befehle für WSL oder Git Bash. In PowerShell schreibst du curl.exe statt curl und führst die Befehle einzeln aus.

  3. Im Browser öffnen: http://<dein-server>:8080. Deck fragt nach einem Einrichtungscode. Den zeigt docker compose logs nodvard-deck im selben Ordner, die Zeile beginnt mit „Einrichtungscode“.
  4. Dem Assistenten folgen. Er führt dich durch dein Konto und den ersten Server. Wer erst mal schauen will, füllt Deck mit Beispieldaten und löscht sie später mit einem Klick.

Port schon belegt?

Lege neben die compose.yml eine Datei .env mit der Zeile NODVARD_DECK_PORT=8081 und führe docker compose up -d noch einmal aus. Deck ist dann unter Port 8081 erreichbar.

Aktualisieren

Im selben Ordner docker compose pull && docker compose up -d. Deine Daten bleiben erhalten. Vor jedem Update, das die Datenbank umbaut, legt Deck selbst eine Kopie an.

Andere Wege

Jeder Weg ist im README Schritt für Schritt beschrieben:

  • Portainer, aus dem Repository oder mit dem Web-Editor
  • Raspberry Pi mit allen Befehlen
  • Ein einzelner docker run-Befehl, Podman oder Dockge
  • NAS: Synology, UGREEN, QNAP, Unraid, TrueNAS SCALE, OpenMediaVault, ZimaOS und CasaOS
  • Proxmox und Docker Desktop
