Features

What Nodvard Deck does today. Parts that are not yet as well tested as the rest carry a Beta label. The interface is in German for now.

Servers and Proxmox

Every server gets its own page with status, load and actions. You add a server in the interface, also with a username and password. You don’t need a terminal for it.

  • Live CPU, RAM, disks and uptime
  • Operating system, failed services and pending updates over SSH
  • Terminal and file manager in the browser
  • Proxmox: start and stop nodes, VMs and LXC, console in the browser, snapshots, hardware and storage
  • Disk health, ZFS and temperature of Proxmox nodes

Proxmox is optional. A Raspberry Pi, a NAS or a few Docker hosts are enough.

Docker

All containers on your servers on one page, with status, logs and console. Stacks from Compose files are shown and handled as a whole.

  • Start, stop, restart, logs with search, console and details
  • Find and apply image updates. The old image stays as a backup. If the new container does not start, Deck goes back on its own, except for databases.
  • Edit Compose files as text or in a form. Before saving, Docker Compose checks the file on the server.
  • Create new stacks, also from templates for Uptime Kuma, Vaultwarden, Nginx Proxy Manager and Gitea
  • Update whole stacks and go back to the previous version, with a backup of the volumes first if you like
  • Move from Portainer: Deck takes over the Compose file and variables, the volumes with your data stay
  • Clean up images, volumes and networks

Nodvard Shield

Shield checks your Linux servers and shows what it finds. You decide what happens next.

  • Virus scans with ClamAV as a quick scan, deep scan or on a schedule, with quarantine
  • Hardening check with Lynis
  • Update center with the pending security updates for each server
  • Intrusion checks: unusual SSH logins, Fail2ban and open ports
  • File watcher for important system files
  • Morning briefing with what happened overnight
  • Optional AI watch for crashed containers, using your own Ollama

Shield sees the most when Deck has sudo rights on the server.

Antivirus for Linux servers

Backups

Deck shows whether your backups really run, and it backs itself up too.

  • All Proxmox backups at a glance, with a warning for missing or failed ones
  • Create and edit backup jobs
  • Restore a guest from a backup as a copy, the original stays untouched
  • Back up the Docker volumes before a stack update if you like
  • A copy of its own database before every Deck update, plus a backup to download and restore

Apps

A start page for the services in your network. Every app is a tile with an address and an icon, sorted into folders.

  • Deck finds containers with a web interface on your Docker servers on its own
  • Add your own apps with an address and an icon
  • Change the order by dragging or through the tile’s menu

Integrations

Deck reads status and numbers from your services and shows them as a tile and a page of their own. Most of them only read and change nothing.

  • Uptime Kuma Beta
  • Home Assistant Beta
  • Plex Beta
  • Jellyfin Beta
  • qBittorrent Beta
  • Synology DSM Beta
  • Pi-hole Beta
  • Nginx Proxy Manager Beta
  • Nextcloud
  • ntfy

There are more modules: scripts for one or many servers, also on a schedule; documents with text recognition and full-text search; an inventory with warranty reminders; game servers Beta. You turn each module on or off on its own.

Vault

Credentials for servers and services are stored encrypted in Deck’s vault.

  • Passwords, API tokens and SSH keys in one place
  • Deck can create a separate SSH key for each server. The private part stays in the vault.
  • Secret values in scripts are taken from the vault only when the script runs
  • Each module can only reach the credentials it has been granted

Notifications

Everything that needs your attention ends up in one list: full disks, failed backups, pending updates and findings from Shield.

  • Push to your phone via ntfy, Telegram, Discord, Gotify, Pushover, Matrix, Slack, Mattermost or your own Apprise API
  • A minimum level for each channel
  • Deck can be added to your phone’s home screen as an app

Approvals and accounts

Everything that changes something is an action with a risk level in Deck. Deck suggests, you confirm. You decide what may run without asking, for example with a block list or a maintenance window.

  • Every action is written to the log
  • Users with roles and permissions
  • Sign-in with a two-factor code from an app
  • Deck’s name, logo and colors are settings
