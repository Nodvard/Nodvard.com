A Portainer alternative for your homelab

Looking for a simple container manager for a few servers? Nodvard Dock is exactly that: containers, stacks, logs and image updates, self-hosted and free for personal use. If you want more, Nodvard Deck comes with the same Docker part. The interface is in German for now.

Move stacks over from Portainer

Stacks created by Portainer move into a folder of their own with one button. Dock takes the Compose file and variables from Portainer’s storage and deploys the stack there again under the same name. The volumes with your data stay.

If something does not fit, for example because the stored file names other images than the running containers, Dock does not move the stack and tells you why.

What Dock does

  • Containers of all servers on one page: status, start, stop, restart, console, details and logs with search.
  • Stacks: edit them as text or in a form. Before saving, Docker Compose checks the file on the server, and recent versions stay in the history.
  • New stacks in a folder on each server, also from templates for Uptime Kuma, Vaultwarden, Nginx Proxy Manager and Gitea.
  • Image updates: find and apply them. The old image stays as a backup. If the new container does not start, it goes back on its own, except for databases.
  • Update whole stacks and go back to the previous version, with a backup of the volumes first if you like. You can restore volume backups in the Stacks tab as well.
  • Private registries such as ghcr.io. The password or token is stored in the vault.
  • Images, volumes and networks: list and clean them up.

Several servers, no agent

Dock talks to your Docker servers over SSH. No agent of its own runs on the servers. If you don’t want to give the account full Docker rights, use the “operate only” mode: Dock may then only call one fixed helper script via sudo, and that script checks every call itself.

Approvals instead of surprises

Every change to containers, stacks, images, volumes and networks is an action with a risk level. The owner decides what runs without asking. Everything is written to the log.

Dock or Deck?

Nodvard Dock is just the container manager, as its own lean image. Nodvard Deck includes the same Docker part plus Proxmox, backups, Shield, apps and notifications. It is the same code, with more or less of it included.

Dock is in beta. Feedback helps, Discord is the quickest way.

Installed with three commands

You need a machine with Docker and Docker Compose. The commands are on the Nodvard Dock page.
