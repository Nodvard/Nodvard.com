Proxmox and Docker in one dashboard

Your VMs and LXC run on Proxmox, and often Docker runs inside them. Nodvard Deck shows you both together, from the node to the guest to the container, with load, backups and updates. The interface is in German for now.

Get startedAll features

Proxmox

You start and stop nodes, VMs and LXC in Deck, and the console runs in your browser. Snapshots, hardware, storage and updates are shown for each guest, plus disk health, ZFS and temperature of the nodes. You connect Proxmox in one step.

More about Proxmox

Docker in your guests

If Docker runs in a VM or an LXC, Deck connects over SSH and shows you that guest’s containers and Compose stacks. If an update goes wrong, you go back to the old version. You edit stacks as text or in a form.

More about Docker

Keep an eye on Proxmox backups

Deck shows all backup jobs with their last run and existing backups. If a guest has no job or a run has failed, it says so at the top. Restoring works as a copy, and the original stays as it is.

More about backups

Without Proxmox, too

You don’t need Proxmox. If all you have is a Raspberry Pi, a NAS or a few Docker hosts, Deck simply shows those. If you add Proxmox later, you just connect it then.

Try it yourself

Deck runs in Docker, on a Raspberry Pi just like on a VM in your Proxmox.
