Proxmox and Docker in one dashboard

Your VMs and LXC run on Proxmox, and often Docker runs inside them. Nodvard Deck shows both together: from the node to the guest to the container, with load, backups and updates. The interface is in German for now.

Get startedAll features

Proxmox

You start and stop nodes, VMs and LXC in Deck, and the console runs in your browser. Snapshots, hardware, storage and updates are shown for each guest, plus disk health, ZFS and temperature of the nodes. You connect Proxmox in one step.

More about Proxmox

Docker in your guests

If Docker runs in a VM or an LXC, Deck connects over SSH and shows that guest’s containers and Compose stacks. You apply updates with a way back and edit stacks as text or in a form.

More about Docker

Proxmox backups at a glance

Deck shows all backup jobs with their last run and existing backups. If a guest has no job or a run has failed, it says so at the top. You restore a guest as a copy, the original stays untouched.

More about backups

Without Proxmox, too

Proxmox is optional. A Raspberry Pi, a NAS or a few Docker hosts are enough, and Deck then simply shows those. If you add Proxmox later, you connect it whenever you like.

Try it yourself

Deck runs in Docker, on a Raspberry Pi just like on a VM in your Proxmox.
