Frequently asked questions

Short answers about cost, data, requirements and the difference between Deck and Dock. Missing something? Ask on Discord.

What does Nodvard Deck cost?

Nothing for personal use. You don’t need an account with Nodvard, there is no subscription and no advertising. Using it in a company needs permission, ask at kontakt@nodvard.com.

Can I read the source code?

Yes. The source code is public on GitHub. Nodvard Deck is licensed under the PolyForm Noncommercial License 1.0.0: you may use it for personal and other noncommercial purposes, read the code and adapt it for yourself. Commercial use needs permission.

Does Nodvard Deck phone home?

No. There is no telemetry and no usage statistics, Deck sends nothing to Nodvard. On its own, it only asks GitHub whether a new version exists. You turn that off under Settings, System, Updates. For image updates, Deck asks the registry of your images, and messages to Telegram, Discord or other services only go out if you set up a channel.

What do I need?

A machine with Docker and Docker Compose, with 64-bit ARM (arm64) or x86-64. Idle, Nodvard Deck uses about 100 MB of RAM, and the image is just under 400 MB. Deck reaches your servers over SSH. No service and no agent of its own runs on them. For tasks that need root, the setup puts small helper scripts into /usr/local/lib/nodvard-deck, which Deck calls via sudo. What each helper script may do.

Does it run on a Raspberry Pi?

Yes, on a Raspberry Pi 4 or 5 with 4 GB of RAM and a 64-bit system. An SD card can fail, so a USB SSD lasts longer, and backups should not stay on the Pi only. The guide Back up to a NAS or NFS share shows how.

Do I need Proxmox?

No. A Raspberry Pi, a NAS or a few Docker hosts are enough. You can connect Proxmox at any time later.

What is the difference between Deck and Dock?

Nodvard Dock is just the container manager for Docker, as its own lean image. Nodvard Deck includes the same Docker part plus Proxmox, backups, Shield, apps, integrations and notifications. It is the same code, with more or less of it included.

Is Nodvard Deck available in English?

The interface is in German for now. The website and the guides are also available in English.

What if I click the wrong thing?

Everything that changes something is an action with a risk level in Deck. Deck suggests, you confirm, and every action is written to the log. You decide what may run without asking. There are also roles for several users and sign-in with a two-factor code.

How do I back up Nodvard Deck?

Under Settings, System, Backup. Backups are encrypted with a password that Deck itself does not store. Before every update that changes the database, Deck also makes a copy of it. The guide explains backups to a NAS.

How do I update?

In the folder with compose.yml: docker compose pull && docker compose up -d. Your data is kept. Other ways, for example with Portainer, are under Get started.

Ready to try it?

Three commands, then Deck is running, with sample data first if you like.
