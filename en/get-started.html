Get started

Nodvard Deck runs in Docker, on a Raspberry Pi 4 or 5 just like on any x86-64 machine. Nothing is built, the ready-made image comes from GitHub. The interface is in German for now.

  1. Have Docker and Docker Compose ready. A Raspberry Pi needs a 64-bit system.
  2. Get Deck and start it.
    In a terminal
    mkdir ~/nodvard-deck && cd ~/nodvard-deck
curl -fsSL -o compose.yml https://raw.githubusercontent.com/nodvard/deck/main/deploy/compose.standalone.yml
docker compose up -d

    On Windows, these commands are for WSL or Git Bash. In PowerShell, write curl.exe instead of curl and run the commands one by one.

  3. Open it in your browser: http://<your-server>:8080. Deck asks for a setup code. docker compose logs nodvard-deck in the same folder shows it, the line starts with “Einrichtungscode”.
  4. Follow the assistant. It guides you through your account and the first server. If you just want to look around, fill Deck with sample data and delete it later with one click.

Port already in use?

Put a file .env next to compose.yml with the line NODVARD_DECK_PORT=8081 and run docker compose up -d again. Deck is then on port 8081.

Updating

In the same folder, run docker compose pull && docker compose up -d. Your data is kept. Before every update that changes the database, Deck makes a copy of it.

Other ways

Each way is described step by step in the README:

  • Portainer, from the repository or with the web editor
  • Raspberry Pi with all commands
  • A single docker run command, Podman or Dockge
  • NAS: Synology, UGREEN, QNAP, Unraid, TrueNAS SCALE, OpenMediaVault, ZimaOS and CasaOS
  • Proxmox and Docker Desktop

All ways in the README
