Nodvard Dock Beta

Container management for Docker, plain and simple. For anyone who wants to keep an eye on the containers on a few servers, including people moving away from Portainer CE.

Available as a ready-made image since version 0.11.0 (beta). Dock is Deck with only the Docker module: the same code, just less of it. The interface is in German for now.

What Dock does

  • Containers of all servers on one page: status, start, stop, restart, delete stopped containers, console and details.
  • Logs with a time range, search and download.
  • Image updates: find them and apply them to Compose services. The old image stays as a backup. If the new container crashes on start, it goes back on its own, except for databases.
  • Stacks: view, adopt and edit them, as text or in a form. You create new stacks in a folder on each server, also from a template.
  • Update whole stacks with “back to the previous version”. If you like, Dock backs up the volumes first and checks that there is enough space.
  • Images, volumes and networks: list and clean them up.
  • Approval and log: every change is an action with a risk level. The owner decides what runs without asking.

Moving from Portainer

Stacks created by Portainer move into a folder of their own. Dock takes the Compose file and variables from Portainer’s storage and deploys the stack there again under the same name. The volumes with your data stay. If something does not fit, Dock does not move the stack and tells you why.

New in 0.11

You restore a stack’s volume backups in the Stacks tab under backups. You add private registries such as ghcr.io in the settings, and the password or token is stored in the vault. For servers whose account should not be in the docker group, there is the “operate only” mode.

More about switching is on the Portainer alternative page.

Install

You need a machine with Docker and Docker Compose, for example a Raspberry Pi 4 or 5 with a 64-bit system or an x86-64 machine.

In a terminal, with Docker Compose
mkdir ~/nodvard-dock && cd ~/nodvard-dock
curl -fsSL -o compose.yml https://raw.githubusercontent.com/nodvard/deck/main/deploy/nodvard-dock/compose.yml
docker compose up -d

Then open http://<your-server>:8080. docker compose logs nodvard-dock shows the setup code. There is more in the Nodvard Dock guide.
