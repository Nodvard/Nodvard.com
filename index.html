NeuStacks aus Portainer mit einem Klick umziehen: Nodvard Dock

Dein Homelab auf einer Seite.

Nodvard Deck zeigt deine Server, Proxmox, Docker-Container und Backups in einer Weboberfläche. Es läuft bei dir zu Hause und kostet für private Nutzung nichts.

Loslegen Auf GitHub ansehen
$ docker compose up -dSo installierst du es

Die Übersicht mit Beispieldaten. Beta, läuft mit Docker auf einem Raspberry Pi 4 oder 5 und auf jedem x86-64-Rechner.

Was Deck kann

Änderungen laufen über Freigaben: Deck schlägt vor, du bestätigst. Was ohne Rückfrage laufen darf, legst du selbst fest.

Docker mit Stacks Neu

Alle Container deiner Server auf einer Seite. Compose-Stacks bearbeitest du als Text oder im Formular, aktualisierst sie mit Weg zurück und holst sie aus Portainer herüber. Die Volumes mit deinen Daten bleiben.

Mehr zu Docker

Server und Proxmox

Jeder Server bekommt eine eigene Seite mit Auslastung, Diensten und offenen Updates. VMs und LXC auf Proxmox startest und stoppst du hier, die Konsole läuft im Browser. Proxmox ist kein Muss.

Nodvard Shield

Virenscan mit ClamAV, Härtungs-Check mit Lynis, offene Sicherheitsupdates und ungewöhnliche Logins. Shield zeigt, was es findet. Was danach passiert, entscheidest du.

Außerdem dabei

Backups

Alle Proxmox-Backups auf einen Blick. Deck warnt, wenn eines fehlt oder fehlgeschlagen ist.

Apps

Eine Startseite mit Kacheln für deine Dienste. Container mit Weboberfläche findet Deck von selbst.

Integrationen

Uptime Kuma, Home Assistant, Plex, Jellyfin, Synology und weitere als Kachel in Deck. Viele davon noch als Beta.

Tresor

Passwörter, API-Tokens und SSH-Schlüssel liegen verschlüsselt in Deck. Für jeden Server kann Deck einen eigenen Schlüssel erzeugen.

Meldungen

Eine Liste für alles, was deine Aufmerksamkeit braucht. Auf Wunsch aufs Handy über ntfy, Telegram, Discord und weitere.

Freigaben und Konten

Rollen, Zwei-Faktor-Anmeldung und ein Protokoll, in dem jede Aktion steht.

Nodvard Dock Beta

Du willst nur deine Container verwalten? Nodvard Dock ist Deck mit nur dem Docker-Teil, als eigenes, schlankes Image. Gedacht auch für alle, die von Portainer CE umsteigen. Erhältlich seit Version 0.11.0.

In drei Befehlen installiert

Du brauchst einen Rechner mit Docker und Docker Compose. Gebaut wird nichts, das fertige Image kommt von GitHub.

Im Terminal, mit Docker Compose
mkdir ~/nodvard-deck && cd ~/nodvard-deck
curl -fsSL -o compose.yml https://raw.githubusercontent.com/nodvard/deck/main/deploy/compose.standalone.yml
docker compose up -d
Was steht in der compose.yml?

Ein Container, ein Port, ein Volume für die Daten. Kein Docker-Socket, keine besonderen Rechte. Die vollständige Datei liegt auf GitHub.

name: nodvard-deck
services:
  nodvard-deck:
    image: ghcr.io/nodvard/deck:latest
    restart: unless-stopped
    ports:
      - "${NODVARD_DECK_PORT:-8080}:8080"
    volumes:
      - nodvard_deck_data:/app/data
    healthcheck: …
volumes:
  nodvard_deck_data:
    name: nodvard-deck-data

Danach öffnest du http://<dein-server>:8080 im Browser. Den Einrichtungscode zeigt docker compose logs nodvard-deck.
