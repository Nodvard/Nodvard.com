Nodvard Dock Beta

Container-Verwaltung für Docker, schlicht und auf Deutsch. Für alle, die ihre Container auf ein paar Servern im Blick behalten wollen, auch für Umsteiger von Portainer CE.

Seit Version 0.11.0 als fertiges Image (Beta). Dock ist Deck mit nur dem Modul Docker: derselbe Code, nur weniger drin.

Was Dock kann

  • Container aller Server auf einer Seite: Zustand, Starten, Stoppen, Neustarten, gestoppte Container löschen, Konsole und Details.
  • Logs mit Zeitraum, Suche und Download.
  • Image-Updates finden und bei Compose-Diensten einspielen. Das alte Image bleibt als Sicherung. Stürzt der neue Container beim Start ab, geht es von selbst zurück, außer bei Datenbanken.
  • Stacks sehen, übernehmen und bearbeiten, als Text oder im Formular. Neue Stacks legst du je Server in einem Ordner an, auch aus einer Vorlage.
  • Ganze Stacks aktualisieren mit „Zurück zur vorigen Version“. Auf Wunsch sichert Dock vorher die Volumes und prüft, ob genug Platz da ist.
  • Images, Volumes und Netze auflisten und aufräumen.
  • Freigabe und Protokoll: Jede Änderung ist eine Aktion mit Risikostufe. Was ohne Rückfrage durchläuft, bestimmt der Inhaber.

Umsteigen von Portainer

Stacks, die Portainer angelegt hat, ziehen in einen eigenen Ordner um. Dock holt Compose-Datei und Variablen aus dem Speicher von Portainer und rollt den Stack dort unter demselben Namen neu aus. Die Volumes mit deinen Daten bleiben. Passt etwas nicht, zieht Dock nicht um und nennt den Grund.

Noch nicht dabei

Volume-Sicherungen über die Oberfläche zurückspielen und das Anmelden bei privaten Registries. Das kommt mit den nächsten Beta-Ständen.

Installieren

Du brauchst einen Rechner mit Docker und Docker Compose, etwa einen Raspberry Pi 4 oder 5 mit 64-Bit-System oder einen x86-64-Rechner.

Im Terminal, mit Docker Compose
mkdir ~/nodvard-dock && cd ~/nodvard-dock
curl -fsSL -o compose.yml https://raw.githubusercontent.com/nodvard/deck/main/deploy/nodvard-dock/compose.yml
docker compose up -d

Danach öffnest du http://<dein-server>:8080. Den Einrichtungscode zeigt docker compose logs nodvard-dock. Mehr steht in der Anleitung zu Nodvard Dock.
