Häufige Fragen

Kurze Antworten zu Kosten, Daten, Voraussetzungen und dem Unterschied zwischen Deck und Dock. Fehlt etwas, frag auf Discord.

Was kostet Nodvard Deck?

Für private Nutzung nichts. Du brauchst kein Konto bei Nodvard, es gibt kein Abo und keine Werbung. Für die Nutzung in einem Unternehmen brauchst du eine Erlaubnis, frag dafür an unter kontakt@nodvard.com.

Kann ich den Quellcode sehen?

Ja. Der Quellcode liegt öffentlich auf GitHub. Nodvard Deck steht unter der PolyForm Noncommercial License 1.0.0: Du darfst es für private und andere nicht-kommerzielle Zwecke nutzen, den Code lesen und für dich anpassen. Kommerzielle Nutzung braucht eine Erlaubnis.

Sendet Nodvard Deck Daten nach Hause?

Nein. Es gibt keine Telemetrie und keine Nutzungsstatistik, Deck schickt nichts an Nodvard. Von sich aus fragt es nur bei GitHub nach, ob es eine neue Version gibt. Das schaltest du unter Einstellungen, System, Updates ab. Für Image-Updates fragt Deck die Registry deiner Images, und Nachrichten an Telegram, Discord oder andere Dienste gehen nur raus, wenn du einen Kanal einrichtest.

Was brauche ich?

Einen Rechner mit Docker und Docker Compose, mit 64-Bit-ARM (arm64) oder x86-64. Im Leerlauf braucht Nodvard Deck rund 100 MB Arbeitsspeicher, das Image ist knapp 400 MB groß. Deine Server erreicht Deck per SSH. Auf den Servern läuft kein eigener Dienst und kein Agent. Für Aufgaben, die root brauchen, legt die Einrichtung kleine Hilfsskripte unter /usr/local/lib/nodvard-deck an, die Deck per sudo aufruft. Was jedes Hilfsskript darf.

Läuft es auf dem Raspberry Pi?

Ja, auf einem Raspberry Pi 4 oder 5 mit 4 GB RAM und einem 64-Bit-System. Eine SD-Karte kann kaputtgehen, deshalb hält eine USB-SSD länger, und die Sicherungen sollten nicht nur auf dem Pi liegen. Wie das geht, steht in der Anleitung Sicherungen auf ein NAS oder NFS.

Brauche ich Proxmox?

Nein. Ein Raspberry Pi, ein NAS oder ein paar Docker-Hosts reichen. Proxmox kannst du jederzeit nachträglich verbinden.

Was ist der Unterschied zwischen Deck und Dock?

Nodvard Dock ist nur die Container-Verwaltung für Docker, als eigenes, schlankes Image. Nodvard Deck bringt denselben Docker-Teil mit und dazu Proxmox, Backups, Shield, Apps, Integrationen und Meldungen. Es ist derselbe Code, nur unterschiedlich viel drin.

Gibt es Nodvard Deck auf Englisch?

Die Oberfläche ist derzeit auf Deutsch. Die Webseite und die Anleitungen gibt es auch auf Englisch.

Was passiert, wenn ich mich verklicke?

Alles, was etwas verändert, ist in Deck eine Aktion mit Risikostufe. Deck schlägt vor, du bestätigst, und jede Aktion steht im Protokoll. Was ohne Rückfrage laufen darf, legst du selbst fest. Dazu gibt es Rollen für mehrere Benutzer und die Anmeldung mit Zwei-Faktor-Code.

Wie sichere ich Nodvard Deck?

Unter Einstellungen, System, Sicherung. Die Sicherungen sind mit einem Passwort verschlüsselt, das Deck selbst nicht speichert. Vor jedem Update, das die Datenbank umbaut, legt Deck außerdem eine Kopie an. Sicherungen auf ein NAS erklärt die Anleitung.

Wie aktualisiere ich?

Im Ordner mit der compose.yml: docker compose pull && docker compose up -d. Deine Daten bleiben erhalten. Andere Wege, etwa mit Portainer, stehen unter Loslegen.

Bereit zum Ausprobieren?

Drei Befehle, dann läuft Deck, auf Wunsch zuerst mit Beispieldaten.
