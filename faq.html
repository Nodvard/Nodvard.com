Häufige Fragen

Kurze Antworten auf die üblichen Fragen. Fehlt deine, frag einfach auf Discord.

Was kostet Nodvard Deck?

Privat nichts. Du brauchst kein Konto bei Nodvard, und es gibt weder Abo noch Werbung. Willst du Deck in einer Firma nutzen, brauchst du eine Erlaubnis. Frag dafür einfach an unter kontakt@nodvard.com.

Kann ich den Quellcode sehen?

Ja, er liegt öffentlich auf GitHub. Deck steht unter der PolyForm Noncommercial License 1.0.0. Privat und für andere nicht-kommerzielle Zwecke darfst du es nutzen, den Code lesen und für dich anpassen. Für kommerzielle Nutzung brauchst du eine Erlaubnis.

Sendet Nodvard Deck Daten nach Hause?

Nein. Deck hat keine Telemetrie und keine Nutzungsstatistik und schickt nichts an Nodvard. Von sich aus fragt es nur bei GitHub, ob es eine neue Version gibt. Das kannst du unter Einstellungen, System, Updates abschalten. Für Image-Updates fragt Deck bei der Registry deiner Images nach. Nachrichten an Telegram, Discord oder andere Dienste gehen nur raus, wenn du dafür einen Kanal einrichtest.

Was brauche ich?

Einen Rechner mit Docker und Docker Compose, mit 64-Bit-ARM (arm64) oder x86-64. Im Leerlauf braucht Nodvard Deck rund 100 MB Arbeitsspeicher, das Image ist knapp 400 MB groß. Deine Server erreicht Deck per SSH. Auf den Servern läuft kein eigener Dienst und kein Agent. Für Aufgaben, die root brauchen, legt die Einrichtung kleine Hilfsskripte unter /usr/local/lib/nodvard-deck an, die Deck per sudo aufruft. Was jedes Hilfsskript darf.

Läuft es auf dem Raspberry Pi?

Ja, auf einem Raspberry Pi 4 oder 5 mit 4 GB RAM und 64-Bit-System. SD-Karten gehen gern mal kaputt. Eine USB-SSD hält länger, und deine Sicherungen sollten nicht nur auf dem Pi liegen. Wie das geht, steht in der Anleitung Sicherungen auf ein NAS oder NFS.

Brauche ich Proxmox?

Nein. Ein Raspberry Pi, ein NAS oder ein paar Docker-Hosts reichen völlig. Kommt später ein Proxmox dazu, verbindest du es einfach nachträglich.

Was ist der Unterschied zwischen Deck und Dock?

Nodvard Dock ist nur die Container-Verwaltung für Docker, als eigenes, kleines Image. Nodvard Deck hat denselben Docker-Teil und obendrauf Proxmox, Backups, Shield, Apps, Integrationen und Meldungen. Der Code ist derselbe, es ist nur unterschiedlich viel drin.

Gibt es Nodvard Deck auf Englisch?

Die Oberfläche gibt es bisher nur auf Deutsch. Webseite und Anleitungen gibt es auch auf Englisch.

Was passiert, wenn ich mich verklicke?

Jede Änderung ist in Deck eine Aktion mit Risikostufe, und bevor sie läuft, fragt Deck nach. Was ohne Nachfrage durchgehen darf, stellst du selbst ein. Hinterher steht jede Aktion im Protokoll. Für mehrere Benutzer gibt es Rollen, und anmelden kannst du dich mit Zwei-Faktor-Code.

Wie sichere ich Nodvard Deck?

Unter Einstellungen, System, Sicherung. Die Sicherungen sind mit einem Passwort verschlüsselt, das Deck selbst nicht speichert. Vor jedem Update, das die Datenbank umbaut, legt Deck außerdem eine Kopie an. Sicherungen auf ein NAS erklärt die Anleitung.

Wie aktualisiere ich?

Im Ordner mit der compose.yml: docker compose pull && docker compose up -d. Deine Daten bleiben erhalten. Andere Wege, etwa mit Portainer, stehen unter Loslegen.

Bereit zum Ausprobieren?

Nach drei Befehlen läuft Deck. Wenn du willst, erst mal mit Beispieldaten.
