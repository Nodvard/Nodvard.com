Wenn du die Seite aufrufst, verarbeitet GitHub technisch notwendige Daten, damit die Seite ausgeliefert werden kann. Domain und E-Mail bei Cloudflare

Die Domain nodvard.com wird bei Cloudflare verwaltet, einem Dienst der Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA. Aufrufe der Seite laufen über die Server von Cloudflare, bevor sie GitHub erreichen. Dabei verarbeitet Cloudflare dieselben technischen Daten wie GitHub, vor allem deine IP-Adresse, um die Seite auszuliefern und vor Angriffen zu schützen. Cloudflare setzt dabei keine Cookies. Keine Cookies, kein Tracking

Diese Seite setzt keine Cookies und speichert nichts in deinem Browser. Es gibt keine Statistik, keine Werbung und keine eingebetteten Inhalte. Schriften und Bilder kommen vom selben Server wie die Seite, nichts wird bei Dritten nachgeladen. Ein Cookie-Banner ist deshalb nicht nötig.
